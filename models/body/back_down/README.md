# Rear Lower Chassis Section

<img src="back_down_image.png" width="400">

The lower rear section of the body. Carries the drive motor mount and the rear axle,
and forms the rear floor of the car.

All drive torque is reacted through this part, so it is stiff for the same reason the
motor mount is: any flex between the motor and the wheels shows up as odometry error.
