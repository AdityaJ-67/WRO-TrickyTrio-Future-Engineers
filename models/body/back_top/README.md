# Rear Upper Chassis Section

The upper rear section of the body. Closes over the drive assembly and carries the
electronics deck, where the Raspberry Pi, the Pico and the sensor board are mounted.

Keeping the electronics on a removable upper section means the whole control system can
be lifted off for wiring work without disturbing the drivetrain underneath.
